# LlanquihueTours
Este proyecto tiene como objetivo gestionar los empleados de una empresa de turismo (Llanquihue Tours), aplicando los principios aprendidos en clases.  El sistema carga los datos desde un archivo .txt, los almacena en una lista y permite: Listar todos los empleados. Filtrar empleados por rol  Filtrar empleados por la ciudad de su dirección
